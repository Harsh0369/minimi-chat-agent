# Design

**Goal.** Answer ordinary questions quickly, remember what the user asked and when, and recheck time-sensitive answers against the web. The agent has one external tool, `web_search`. It runs with `npm install` and `npm run dev` on Node 24. Required keys are listed in `.env.example`.

**Flow.** Express validates the request and atomically records a user message and pending turn. A worker owns SQLite, so HTTP handlers never run SQL directly. The server retrieves exact-day matches and relevant FTS5 messages across this browser workspace, along with conversation context. Gemini receives the current time, timezone, original dated messages, and a narrow web-search function declaration. It may answer or make at most four search calls, running independent calls together. Tavily returns bounded results with source IDs, excerpts, publication dates where present, and observation timestamps. The server accepts only citations to IDs it actually returned and commits the answer and cited source snapshots in one database transaction. A failed turn remains retryable; interrupted turns are marked on restart.

**Time and evidence.** Exact calendar dates are resolved in the user's IANA timezone before querying stored UTC timestamps. A missing dated memory produces a direct “I can't find it” response. Prior answers are preserved as dated records, not silently rewritten. The model is instructed to distinguish a current observation from proof of when a change occurred and to avoid claiming a price changed without comparable earlier evidence. Search content is untrusted input. Citation-ID checking prevents fabricated links, but it cannot prove that a cited page supports every sentence; live quality evaluation is still required.

**Reliability.** One active turn is allowed per conversation and three answers globally. There is a 45-second answer deadline, bounded database queue, input size limits, local-origin enforcement, owner-scoped reads, no permissive CORS, and no credentials in browser bundles or request logs. Browser sessions are anonymous local workspaces; losing the cookie loses access to that workspace. Public hosting and cross-device synchronization would need sign-in, spending controls, and likely PostgreSQL.

**Choices.** Express fits this small API and the author's experience. SQLite keeps local setup to one process; FTS5 plus explicit date queries is simpler and more exact for the challenge's named-date examples than embedding every message. A vector index, multi-agent framework, and model picker would add state, latency, and cost before evidence they improve the judged tasks. Gemini's eligible free tier and Tavily's free search quota support a low-cost local run, subject to account limits and Gemini's unpaid-tier data-use terms.

**Another week.** Run held-out conversations with live keys; score dated recall, unsupported claims, source relevance, correction quality, latency, and quota use. Compare FTS5 with selective embeddings on paraphrases, add a stronger evidence verifier if it measurably reduces false change claims, and improve recovery for longer histories. No quality score or live provider reliability claim is made without those runs.
