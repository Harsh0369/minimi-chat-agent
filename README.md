# minimi chat agent

Design-stage repository for Harsh Agarwal's minimi Software Engineering Intern challenge.

The architecture is proposed. Application implementation, dependency installation, live model evaluation, and startup verification remain future work.

- [DESIGN.md](DESIGN.md) contains the concise submission design.
- [Architecture review](docs/ARCHITECTURE.md) records requirements, decisions, edge cases, evaluation gates, and sources.
- [.env.example](.env.example) lists the planned provider credentials and configuration.

The completed application must run with `npm install` followed by `npm run dev`, after supplying the documented credentials. These commands become available when implementation adds `package.json`.
